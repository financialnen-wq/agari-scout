# AGARI 스카우팅 리포트 ⚾

2026 서울시민리그(S리그) 일요리그 **AGARI vs 디펜스원**(10월 11일(일) 12:00 신월야구장)을 위한 선수 기록 대시보드입니다.

👉 **대시보드 바로가기: https://financialnen-wq.github.io/agari-scout/**

## 무엇을 볼 수 있나

| 탭 | 내용 |
|---|---|
| 타자 | 타율·출루율·장타율·OPS, 삼진/볼넷 비율, **땅볼/라이너/뜬공 비율**, 땅볼아웃/뜬공아웃(GO/AO), **야구장 방향별 타구 비중**(11개 구역), 당겨치기/밀어치기, 경기별 타석 결과 |
| 투수 | 방어율(7이닝 기준)·WHIP·삼진/7·볼넷/7·K/BB·피안타율·승패, 경기별 투구 기록 |
| 수비 위치 카드 | 타자별 타구 분포 + **권장 수비 위치**(내·외야 이동, 외야 깊이) — 인쇄(A4) 또는 PNG 저장 |

상단에서 팀(디펜스원/AGARI), 시즌(2025·2026·전체), 범위(모든 경기/S리그만)를 바꿀 수 있습니다.

## 데이터 출처와 범위

- **선수 범위**: S리그 출전이 확인된 선수
  - [S리그 기록실](https://www.sleague.or.kr/2026/baseball/result/player_attack_ranking.php) 2026 (규정 10타석 이상만 노출)
  - [게임원](https://www.gameone.kr) 박스스코어 중 '서울시민리그(S-리그)' 경기 출전자
- **기록**: 게임원 라커룸의 '게임별기록' — 그 선수가 **게임원에 등록된 모든 팀**에서 뛴 2025~2026 경기 전부
  - AGARI = 게임원 '아가리 OB'(19129)·'아가리OB 2'(43281), 디펜스원 = 31183
  - ⚠️ AGARI는 2026 시즌 경기가 게임원에 올라와 있지 않아 2025 위주입니다. 2026 S리그 성적은 선수 상세의 'S리그 공식 기록실' 표를 보세요.
- **타구 분류**: 게임원 타석 코드를 자동 해석 (`scripts/classify.py`)
  - `유땅` 유격수 땅볼 · `좌플` 좌익수 플라이 · `중직` 중견수 라이너 · `좌선2` 좌익선상 2루타 · `우월홈` 우측 담장 넘는 홈런 · `3내안` 3루 내야안타
  - 외야 안타 중 궤적 표기가 없는 타구(예: `좌안`)는 방향에는 넣고, 땅볼/뜬공 비율에서는 뺍니다.

## 파일

```
data/hitters.csv     타자 집계 (시즌 × 범위별, 엑셀에서 바로 열림)
data/pitchers.csv    투수 집계
data/raw/            수집 원자료 (S리그·게임원)
docs/                대시보드 (GitHub Pages)
scripts/             수집·집계 코드
```

## 기록 업데이트 (관리자용)

```bash
python3 scripts/sleague.py    # S리그 기록실
python3 scripts/gameone.py    # 게임원 팀 일정·박스스코어
python3 scripts/players.py    # 선수별 전 경기 (수 분 소요)
python3 scripts/build.py      # 집계 → docs/data.js, data/*.csv
git add -A && git commit -m "기록 업데이트" && git push
```

수집은 서버 부담을 줄이려고 요청 사이에 0.4~0.8초 간격을 둡니다.
